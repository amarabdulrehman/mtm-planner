How it works

Four steps.
One of them uses AI.

The model only reads. Code does the planning, so the arithmetic is always right and every decision can be traced back to a message.

Read

One call to a small model turns every message, in English or Roman Urdu, into typed facts: who sent it, on which channel, on what date.

1 model call

Weigh

Newest message wins. Only the right person can change each fact: the caterer sets prices, the organiser sets the budget. Clashes are flagged, not hidden.

Code

Plan

Headcount, cheapest hall that fits, meals for everyone, a judge timetable with no double-booking, and a schedule built around fixed times.

Code

Check

Seven checks run on every update. If a message would break the plan, that message is rejected with a plain reason, and the plan stays valid.

Features

Built for the people
running the day.

Not a chatbot. A planner that keeps its promises when the messages keep changing.

🛡️

Catches the wrong message

A student asking to raise the budget, a caterer quoting yesterday's price, a request that would leave guests without a meal: each is rejected with the reason, and the plan stays valid.

Rejected · Student society: "Budget 10 lakh kar dein" → only the organiser can change the budget.
⚡

Updates in seconds

New message in, new plan out: usually one model call and a few seconds. Only what changed is re-read.

🎙️

Just say it

Type, paste, upload a .txt, or speak the message. Voice input runs in your browser, so it costs no model tokens.

✉️

Replies, written for you

A reply for every sender on the channel they used: WhatsApp for the caterer, email for the dean. One tap to open, you press send.

🔍

See what changed

Every update shows each cost, seat, meal and time slot that moved, with arrows and the reason why.

🧾

Every call on the record

Each model call is numbered with its model, area, full input and output, tokens and time. Nothing is hidden behind "AI magic".

🗓️

A schedule that respects the clock

Prayer breaks, hall changeovers and fixed judging windows are placed first; build time fills the gaps. Every judge gets a timetable.
